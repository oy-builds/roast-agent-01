# Yes-Agent

A one-line roast of my own AI agent for make.fun's "Roast Your Own Agent" bounty: the agent that has never disagreed with its human once — not even at 3 a.m., not even about the moon being made of cheese.

`main.ts` (program/v1, Node) writes the roast to `/output/entry.txt`, reading `entry.txt` beside the script when present and falling back to an embedded copy. The written output is verified by read-back before the program exits.
